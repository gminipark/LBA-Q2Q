# LBA-Q2Q: Learning by Asking — Question-to-Question Generation

Research codebase for **Learning by Asking (LBA)** Question-to-Question (Q2Q) generation, visual disambiguation, and dialogue-driven Knowledge Graph (KG) expansion across multiple project phases (`2023`–`2026`).

## Repository Structure

```bash
LBA-Q2Q/
├── 2023/   # Ambiguous VQA dataset construction, scene graphs, models, and evaluation
├── 2024/   # Fine-tuning and in-context Q2Q / final VQA pipelines
├── 2025/   # ICQA zero-shot / multimodal evaluation scripts
└── 2026/   # DramaQA interactive VLM sub-questioning, KG expansion, and FastAPI web demo (see 2026/README.md)
```

For usage instructions on the latest DramaQA interactive Q2Q and KG expansion system, see [2026/README.md](2026/README.md).
